# Liquid Glass · 液态玻璃

Translucent specular glass, cool porcelain highlights and crisp Apple-blue controls.

DSH Skin 官方推荐系列 / liquid-glass。这里的“官方”指 DSH Skin 项目，与 DeepSeek 及参考设计品牌无隶属或授权关系。

安装 [DSH Skin](../../../README.md#安装)，在「插件 → 皮肤大全」中选择这款主题。

## 设计与维护

- 设计模式：liquid-glass；底色 #F4F7FC，文字 #182230，标志色 #0E5FD8。
- 可操作控件使用 #0E5FD8 / #FFFFFF 配对；文字、边框、禁用态分别处理。
- `skin.css` 为作用域内的结构样式；`tokens.json` 与 `tokens.dark.json` 为完整明暗模式 token 覆盖。
- 修改后在仓库根目录运行 `pnpm run build:plugin`，并提交生成的 `plugin/client.js`。
- `preview.html` 为离线设计样张，不作为客户端实测证据。
