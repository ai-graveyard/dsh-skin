# Whale Courier · 鲸鱼娘

新会话有鲸鱼信使的全身插画，展开的侧栏底部是捧着信封的头像，输入框边沿是一枚鲸尾火漆。侧栏头像使用独立的空间，会话列表可以照常滚动。

在 `dsh-skin` 0.4.6 的「插件 → 皮肤大全」中选择「鲸鱼娘」。英文界面显示为「Skin Collection → Whale Courier」。

在「设置 → 通用 → 外观」选择浅色、深色或跟随系统。鲸鱼娘的配色和主题卡预览会随之切换。浅色使用冷蓝白设置面板和象牙白输入框，深色使用深海蓝面板和对应的代码语法配色。

## 设计来源

社区形象参考来自上善无形的「溟月」及 ZipZipPipe 的鲸鱼女仆二次设计。对应作者署名和作品入口见 [Deep Whale](https://github.com/Small-tailqwq/dsh-deep-whale#版权所有人)。本套皮肤的主题插画是为项目用 ImageGen 生成的原创鲸鱼信使，采用短冰蓝发、鳍耳、披风、鲸尾和火漆信封。

`courier.webp` 和 `courier-sidebar.webp` 随插件离线打包。桌面验收范围见 [DESKTOP-QA.md](../../../DESKTOP-QA.md)。可在本地打开 [设计样张](./preview.html) 查看配色。
